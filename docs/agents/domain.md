# Domain Docs

This project uses a single-context domain layout.
- `CONTEXT.md` at the root contains the ubiquitous language and domain glossary.
- `docs/adr/` contains Architecture Decision Records (ADRs).

## Domain Terminology & Tone
- **Ban**: "B2B", "Logistik", "Estimator", "Pemasaran", "Pasokan", "Solusi".
- **Tone Rule**: Friendly but professional baker ("kami"). Speak directly to shop owners without corporate buzzwords. Ensure website copy stays human and avoids AI-generated marketing fluff.
