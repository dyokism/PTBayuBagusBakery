# AGENTS.md

> Project context and executable commands for AI agents.

## Setup
- Install: `bun install`

## Development
- Run: `bun run dev`
- Build: `bun run build`
- Preview: `bun run preview`

## Testing
- Test: `bun test` (no test suite configured)

## Code Style & Architecture
- Stack: Vanilla JS (ES Modules) and modular CSS bundled with Vite.
- Aesthetic: Heritage industrial ledger style ("Old but Gold") using Oxford Navy `#141E28`, Stamp Red `#8E2424`, and parchment `#FAF7F2`.
- UI Rules: No nested card containers, drop shadows, or SaaS badges; rely on hairline borders (`#D8D0C5`) and double rules (`3px double #C5BCAD`).
- B2B Workflows: Pure inquiry profile with direct WhatsApp routing; no cart, checkout, or client-side pricing calculators.
- Typography: Playfair Display for editorial headlines, Plus Jakarta Sans for body copy and specification tables.
- Content Standards: Authentic Indonesian language, zero AI filler phrases, no semicolons or em dashes.
